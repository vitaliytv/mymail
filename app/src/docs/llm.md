## Огляд

Надає єдиний конфігурований доступ до локального OpenAI-compatible LLM для функцій листів. Зберігає лише адресу сервера й модель, а API key тримає лише в пам’яті застосунку.

## Поведінка

- `normalizeBaseUrl` приймає тільки повний HTTP(S) URL до `/v1/` і приводить його до канонічної форми.
- `useLlm` завжди використовує `local-openai`, мігрує попередні налаштування `omlx`, `turbofieldfare` і `litellm` та не звертається до прихованих конфіг-файлів.
- Якщо URL не збережено, бере лише стартове значення з нативної команди; за його відсутності повертає зрозумілу помилку налаштування.
- Перевіряє endpoint через список моделей, автоматично обирає першу модель і надсилає явні URL, модель та тимчасовий ключ у кожному чат-запиті.

## Гарантії поведінки

- API key не потрапляє в `localStorage`.
- Завислий запит можна обмежити UI-таймаутом.

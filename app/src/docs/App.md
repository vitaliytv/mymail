## Огляд

Файл визначає початковий екран застосунку та маршрут переходу до основної частини інтерфейсу після входу. Також він задає поведінку навігації між ключовими екранами, щоб користувач міг швидко перейти від авторизації до роботи з доступними розділами.

## Поведінка

1. Ініціює основний layout застосунку та показує екран входу як базову точку взаємодії.
2. Після успішної автентифікації відкриває панель задач для користувача.
3. Коли користувач стає автентифікованим, запускає новий перегляд доступних шаблонів і на його основі оновлює список задач.
4. Під час активного сканування відображає стан процесу та лічильники прогресу, щоб користувач бачив обсяг уже перевіреного й загального обсягу.
5. Дозволяє завершувати задачу й відкривати пов’язане повідомлення без виходу з поточного екрана.
6. Підтримує автоматичне оновлення застосунку через вбудований updater.
